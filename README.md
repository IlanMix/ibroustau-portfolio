# Portfolio BTS SIO SLAM

Site Astro. Tout le contenu se modifie dans `src/data/` (profil, cv, stages, ateliers, veille, compétences).

## Lancer en local
```bash
npm install
npm run dev
```

## Mettre en ligne (GitHub Pages)
1. Adapter `site` et `base` dans `astro.config.mjs`.
2. Pousser sur la branche `main`.
3. Sur GitHub : Settings → Pages → Source : **GitHub Actions**.

## Ajouter ton CV
Dépose ton fichier dans `public/` sous le nom `cv-ilan.pdf`.
